# Suivi des cours de tennis – samedis

Mini site pour suivre quels samedis ont été payés par :
- Albertine & Gaby
- Emilie & Paul

Période couverte :
- 10 octobre 2026
- jusqu’au 15 juillet 2027

## 1. Préparer le projet
Crée un repo GitHub vide.
Ajoute les fichiers :
- index.html
- styles.css
- app.js

## 2. Configurer Supabase
Dans Supabase :
1. Crée un projet
2. Va dans SQL Editor
3. Exécute le script SQL ci-dessous
4. Copie l’URL du projet et la clé anon
5. Remplace dans app.js :
   - SUPABASE_URL
   - SUPABASE_ANON_KEY

## 3. Déploiement
Tu peux le publier sur GitHub Pages ou un hébergement statique.
Le site fonctionne en HTML + JS.

## 4. Utilisation
- Ouvre le site
- Clique sur le bouton correspondant à la famille qui a payé
- La donnée est stockée dans Supabase et visible par tous# Tennis-tracker
